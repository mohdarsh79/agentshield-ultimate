# Security Policy

## Reporting Vulnerabilities
The AgentShield Ultimate maintainers treat security vulnerabilities with top priority.

If you discover a security vulnerability in AgentShield Ultimate:
1. **Do not create a public GitHub issue.**
2. Send an email to the security response team or open a private GitHub Advisory.
3. Include detailed steps to reproduce the vulnerability, including sample prompts or action contexts.

## Security Disclosures & Response Time
- Initial acknowledgment: Within 24 hours.
- Triage & remediation timeline: Within 72 hours for Critical/High vulnerabilities.
